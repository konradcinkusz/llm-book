\chapter{Models, Messages and Runnables}
\label{ch:models}

\begin{quote}\itshape
One interface, four methods, and an \texttt{a} prefix. That is nearly the whole
of LCEL.
\end{quote}

\noindent
Underneath every component in LangChain is one interface with a small, regular
surface: \api{invoke}, \api{batch}, \api{stream}, \api{stream\_events}, each with
an async twin whose name is the same with an \code{a} in front. Learn the four
and the naming rule and you can drive anything in the library without reading its
documentation. This chapter also covers the part of 1.0 that quietly removed the
most code from real projects: standard content blocks.
