\chapter{Interrupts, Time Travel and Streaming}
\label{ch:interrupts}

\begin{quote}\itshape
A graph paused for approval is not a process holding a thread. It is a row.
\end{quote}

\noindent
Three features that look unrelated and are the same feature. Because state is a
serialised value rather than a program counter, a run can stop, be inspected,
be edited, be resumed days later in a different process --- and can be streamed
out while it happens. This chapter covers the human-in-the-loop patterns that
matter in practice, the debugging capability nobody uses enough, and the
streaming surface that most of the perceived quality of an agent product depends
on.

after the gate, never before it.
