\begin{warning}
\textbf{Date every piece of material you find.} If it contains
\api{AgentExecutor}, \api{initialize\_agent}, \api{LLMChain} or
\code{langchain.chains}, it predates October~2025 and describes an architecture
that no longer exists. Apply this to model output as well as to search results:
an assistant asked for LangChain code will confidently produce the retired API.
\end{warning}

\section{How this book was verified, and where it was not}
\label{sec:appE-verification}
\index{verification!method}
\index{measurement!what is unrun}

Every listing was executed against the pinned versions. No chapter carries a
\emph{run this before you trust it} marker, which is the standard rather than an
achievement --- the marker exists precisely so that unverified material can ship
visibly rather than silently.

\textbf{Where the package contradicted the documentation}, and the package won:

\begin{itemize}[leftmargin=1.4em,nosep]
\item \api{create\_react\_agent} is deprecated, not removed.
\item The 1.0 release date is 17 October 2025 --- the PyPI upload --- not the
      22nd, which is the announcement.
\item The call-limit middleware has no \code{limit=} parameter.
\item The summarisation middleware has no \code{max\_tokens\_before\_summary}.
\item Node timeouts work only on async nodes, and say so.
\item No in-box fake chat model implements \code{bind\_tools}.
\item The default \code{recursion\_limit} is 10007, not 25.
\end{itemize}

The last of those was found during a consistency pass, and this book had printed
the wrong number twice before anyone read the value out of the installed
package. It is the cleanest illustration in the book
of why the rule is worth keeping: 25 is not a guess, it is a \emph{memory} --- it
was the default before 1.0, it is what the search results say, and it is what an
assistant will tell you with complete confidence. A remembered fact and a
verified one are indistinguishable from the inside, which is the entire argument
for going and looking.

\textbf{What is measured, and what is not.} Four experiments produced numbers,
all reproducible without a provider: concurrency (Ch.~\ref{ch:asyncio}), service
throughput (Ch.~\ref{ch:serving}), context strategies (Ch.~\ref{ch:context}) and
topology overhead (Ch.~\ref{ch:multi-agent}).

Three things are \emph{not} measured, need a provider budget, and are labelled as
judgement wherever they appear: multi-agent answer quality, tool-selection
accuracy against tool count, and cache hit rate. The tables for them in
Appendix~\ref{app:cheatsheet} are deliberately empty.

\begin{note}
The habit is the transferable part. This book will go stale --- the ecosystem
ships weekly, and the exact import paths will move. What will not go stale is the
practice that produced it: read the installed package, run the listing, and when
you cannot verify something, say so in the text rather than rounding up.
\end{note}
